Air Quality Analysis – EDA

A Minor Project (CA1) based on Exploratory Data Analysis of Air Quality Data in India.

Analytical Question

How do average pollutant levels vary across different pollutants and states, and which pollutants and locations show relatively higher pollution levels?

Tools Used

Python

Pandas

NumPy

Matplotlib

Jupyter Notebook

Dataset

AirData.csv contains air-quality observations from monitoring stations in India, including pollutant type, location, and minimum, maximum, and average readings.

Analysis

The project includes:

Data loading and understanding

Data cleaning and quality checks

NumPy array operations

Distribution of pollutant readings

Comparison of average pollutant levels

State-wise PM10 analysis

Visualizations and observations

Key Finding

PM10 has the highest average recorded reading among the pollutants analysed, followed by PM2.5. The analysis also shows variation in PM10 readings across states.
